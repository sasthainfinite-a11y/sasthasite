SASTHA INFINITE ENTERPRISE WEBSITE
==================================

FILES
- index.html: Complete responsive website (HTML, CSS and JavaScript included)
- assets/sastha-logo.png: User-provided company logo

HOW TO PREVIEW
1. Extract the ZIP file if it is zipped.
2. Open index.html in Chrome, Edge, Firefox or Safari.
3. Test the navigation and enquiry form. The form prepares a message in WhatsApp or the visitor's default email app.

ENQUIRY FORM BEHAVIOUR
This is a static website and does not require a server to display. Submitting the form opens WhatsApp with a pre-filled message to +60 10-280 5889. The Email option opens the visitor's configured email application addressed to sasthainfinite@gmail.com. The visitor must confirm/send the message inside the chosen app. No form data is stored by this website.

PUBLISHING ONLINE
You can publish this folder to any static website host that serves HTML files, including Render Static Sites, Netlify, GitHub Pages or a cPanel hosting account. Upload the contents of this folder and make sure index.html is at the site root. For a Render Static Site, connect the repository containing these files, set the publish/root directory to the folder containing index.html, and use no build command.

BEFORE PUBLISHING
- Confirm contact number, address, registration details, and every listed service are correct.
- If you want enquiries saved to an admin dashboard or sent automatically without opening WhatsApp/email, a backend or third-party form service will be needed.
- Service scope and availability should be confirmed for each customer enquiry.
